  → 真 APK：`D:\ai-build\rhodesisland\app-build\outputs\apk\debug\app-debug.apk`（versionCode 8 / versionName 3.1）。
  → `app\build\outputs\...` 下是**陈旧残留 APK（versionCode 3）**，用它会报 `INSTALL_FAILED_VERSION_DOWNGRADE`。
- **装机**：`& "C:\Users\Lfq06\AppData\Local\Android\Sdk\platform-tools\adb.exe" install -r <真 APK>`（保留数据；设备 id 曾为 `4b0cd2e3`，交接时已断开）。
